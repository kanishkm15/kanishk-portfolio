KANISHK M — PORTFOLIO WEBSITE

HOW TO RUN
1. Extract this ZIP file.
2. Open the kanishk_portfolio folder.
3. Double-click index.html (or open it in VS Code and use Live Server).

ADD YOUR PROFILE PHOTO
1. Open the assets folder.
2. Copy your photo into it.
3. Rename the photo to: profile.jpg
4. Keep the photo in the assets folder. The website already points to assets/profile.jpg.

RESUME
Your uploaded resume is already copied into assets/Kanishk_Resume.pdf.
To update it later, replace that PDF but keep the same filename.

LIVE BACKGROUND
The colourful animated background is made with CSS, so it works without a video file.
The file you mentioned ending in .crdownload is an incomplete browser download. Finish downloading it first if you want to use it as a video background. The current design does not need it.

EDIT DETAILS
Open index.html in VS Code and change the text, email, phone number, LinkedIn and YouTube links as needed.
The website uses only HTML, CSS and JavaScript. No installation is required.
